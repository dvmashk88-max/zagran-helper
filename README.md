# Загран-помощник

Бесплатный статический сервис для граждан РФ 18+, который готовит пользователя к подаче заявления на загранпаспорт от начала до конца. Это не сайт МВД или Госуслуг и не юридическая гарантия принятия заявления.

## Что умеет сервис

- восстанавливает локальный черновик и точный последний шаг в течение 24 часов;
- сам ведёт пользователя назад по работе, учёбе, службе и периодам без работы за последние 10 лет;
- показывает процент заполнения, временную шкалу, конкретные пропуски и пересечения;
- объясняет различие между фотографией для электронного заявления и фотографированием при оформлении биометрического паспорта;
- проверяет ответы и ведёт из каждой ошибки прямо на нужный шаг с возвратом к проверке одним нажатием;
- составляет только применимый пользователю список подготовленных данных и документов;
- раскладывает сведения по блокам для копирования в официальное заявление;
- открывает официальную услугу Госуслуг в новой вкладке;
- помогает создать подтверждённую учётную запись или восстановить доступ без передачи данных ЕСИА;
- показывает отдельный маршрут личной подачи через МВД или оснащённый МФЦ;
- отделяет финальный комплект в самостоятельный экран и модуль, перед которым позднее можно поставить контроль доступа. Сейчас переход бесплатный.

## Приватность анкеты

Анкета не имеет backend. ФИО, паспортные данные, адреса и деятельность хранятся только в `localStorage` под ключом `zagran-helper:draft`, не попадают в URL и удаляются через 24 часа после последней активности. `finishApplication()` полностью удаляет ключ.

Сетевой код основного приложения знает только пять фиксированных событий: `visit`, `start`, `reached_review`, `kit_ready`, `gosuslugi_click`. Их payload содержит единственное поле `event`. Отзыв содержит только выбранную оценку и текст, который пользователь сам вводит в отдельное поле. Объект анкеты не передаётся компоненту отзывов или функциям аналитики.

Если `VITE_PUBLIC_METRICS_ENDPOINT` пуст, сетевые запросы не выполняются, отзыв честно помечается как неотправленный, а публичный счётчик не показывается. Фиктивных чисел нет.

## Обезличенная статистика и отзывы

Для статического GitHub Pages подготовлен изолированный Cloudflare Worker + D1 в `feedback-worker/`. Это простой вариант на бесплатном тарифе:

Пошаговая инструкция подключения находится в `feedback-worker/README.md`. Для завершения нужны вход владельца в Cloudflare, создание D1 и добавление публичного URL Worker в переменную GitHub Actions `VITE_PUBLIC_METRICS_ENDPOINT`.

Worker принимает только allowlist событий, агрегирует дневные количества и отдельно хранит оценку/текст отзыва. Код не читает и не записывает IP, User-Agent, cookies или идентификатор посетителя. Публичный метод возвращает только реальное суммарное число подготовленных комплектов. Административные метрики и тексты отзывов публичным методом не отдаются.

Endpoint намеренно не развёрнут автоматически: для этого нужны аккаунт и явное решение владельца. До подключения приложение остаётся полностью локальным.

## Нормативная модель

Последняя ручная проверка: **22 сентября 2026 года**.

- `FORM_5Y_186 = CURRENT` — Приказ МВД России от 31.03.2021 №186.
- `FORM_10Y_996 = CURRENT` — Приказ МВД России от 31.12.2019 №996.
- `FORM_83 = FUTURE_DISABLED` — не активируется автоматически только потому, что документ новее.

Официальная услуга: <https://www.gosuslugi.ru/600101/1/form>. Ссылка фиксирована, не содержит данных пользователя и открывается в новой вкладке.

Для личной подачи совершеннолетнего заявителя регламенты предусматривают:

- паспорт на 5 лет: МВД или МФЦ, два экземпляра заявления, паспорт РФ и три фотографии 35 × 45 мм;
- биометрический паспорт на 10 лет: МВД или технически оснащённый МФЦ, один экземпляр заявления и паспорт РФ; цифровое фотографирование и дактилоскопия выполняются при приёме;
- действующий загранпаспорт, заявление об утрате и специальные документы добавляются только для соответствующего случая.

МФЦ показывается с оговоркой о предварительной проверке доступности услуги и оборудования в конкретном центре. Самодельный официальный бланк не генерируется.

## Границы текущей версии

- поддерживается одна запись об изменении ФИО и один действующий загранпаспорт;
- точный перечень действий и документов нужно дополнительно сверять с персональными уведомлениями Госуслуг/МВД;
- сервис не анализирует фотографии, сканы или трудовую книжку;
- несколько изменений ФИО, несколько паспортов, дополнительные листы и особые случаи требуют дальнейшей нормативной проработки;
- формы и статус источников нельзя переключать без ручной проверки вступления нормы в силу, состава полей и новых тестов.

## Публикация

Workflow `.github/workflows/pages.yml` автоматически запускается при каждом push в `main` и также допускает ручной запуск. Vite применяет base path `/zagran-helper/` в GitHub Actions. Никакие Railway/DNS-настройки проекту не нужны.
