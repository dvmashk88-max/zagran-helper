# Загран без головняка

Локальный MVP для граждан РФ 18+, который помогает собрать и проверить сведения для заявления на заграничный паспорт. Сервис не входит в Госуслуги, не просит данные авторизации и не принимает решение о выдаче паспорта.

## Возможности

- мастер из 11 коротких шагов для паспортов на 5 и 10 лет;
- проверки обязательных полей, дат и формата внутреннего паспорта;
- официальные вопросы об обстоятельствах возможного ограничения выезда;
- периоды работы, учёбы, службы и отсутствия работы за последние 10 лет;
- обнаружение пропусков, пересечений и обратной последовательности дат;
- лист подготовленных данных, печать/сохранение в PDF и копирование значений для Госуслуг;
- локальный черновик с TTL 24 часа и подтверждённая очистка после завершения;
- безопасные фиктивные сценарии для формы №186 и №996.

## Запуск

Требуется Node.js 22+.

```bash
npm ci
npm run dev
```

Проверки и сборка:

```bash
npm test
npm run build
```

## Архитектура и приватность

Интерфейс написан на React + TypeScript и собирается Vite. Конфигурации форм изолированы в `lib/forms.ts`; правила десятилетнего периода — в `lib/timeline.ts`; проверка анкеты — в `lib/validation.ts`; жизненный цикл локального черновика — в `lib/storage.ts`.

Содержимое анкеты хранится только в `localStorage` под ключом `zagran-helper:draft`. Приложение не содержит backend для анкет, аналитики, error tracking, телеметрии и вызовов сторонних API. Данные не попадают в URL. Просроченный черновик уничтожается до отображения. `finishApplication()` удаляет ключ и программно проверяет его отсутствие.

## Нормативная база

Последняя ручная проверка: **22 сентября 2026 года**.

- `FORM_5Y_186 = CURRENT` — Приказ МВД России от 31.03.2021 №186, Приложение №1: <https://www.consultant.ru/document/cons_doc_LAW_384459/8b22509946c5d2432ec98f1b5258b6e4e0116e7f/>
- `FORM_10Y_996 = CURRENT` — Приказ МВД России от 31.12.2019 №996, Приложение №1: <https://www.consultant.ru/document/cons_doc_LAW_346719/9fe815b10ec4eae054479cb93dc888ac4ef30a1f/>
- `FORM_83 = FUTURE_DISABLED` — Приказ МВД России от 24.02.2026 №83 опубликован, но на дату проверки не используется приложением: <https://www.consultant.ru/document/cons_doc_LAW_533696/>

Нельзя переключать CURRENT-форму автоматически. Обновление требует ручного подтверждения владельца: проверить вступление документа в силу, сравнить каждое поле и приложение, обновить конфигурацию и валидаторы, добавить тесты, пройти оба фиктивных сценария, затем изменить статус.

## GitHub Pages

Workflow `.github/workflows/pages.yml` запускается только вручную (`workflow_dispatch`), чтобы исключить случайную публикацию. Перед первым запуском нужно вручную включить GitHub Pages с источником **GitHub Actions** и проверить артефакт `dist`. Vite применяет base path `/zagran-helper/` только в GitHub Actions. Публичная публикация не выполнялась.

## Ограничения MVP

- результат — явно маркированный **лист подготовленных данных**, а не приблизительная копия официального бланка;
- поддерживается одна запись об изменении ФИО и один действующий загранпаспорт; дополнительные записи требуют ручной сверки с приложениями;
- приложение о детях до 14 лет для паспорта на 5 лет не реализовано;
- техническая проверка фотографии не реализована до отдельной нормативной сверки;
- структурированные адресные поля, официальные дополнительные листы и точное воспроизведение PDF-форм не реализованы;
- формулировки и порядок экранов Госуслуг могут меняться; автоматического входа или отправки нет;
- 10-летний диапазон считается помесячно от текущего месяца включительно и требует ручной проверки владельцем с разъяснениями к официальной форме.

## Безопасность репозитория

В тестах используются только очевидно фиктивные значения (`0000 000000`, `ООО «ТЕСТ»`, домен `.test`). Секреты и реальные персональные данные не нужны и не должны добавляться в репозиторий.
